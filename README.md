# Famiglia De Angelis S.r.l. — Sito Web

Landing page per **Famiglia De Angelis S.r.l.** (CineArs), laboratorio di scultura e scenografia
cinematografica negli Studi di Cinecittà dal 1919.

## Contenuto

Sito interamente statico in un unico file (`index.html`) — HTML5, Tailwind CSS (via CDN), JavaScript
vanilla e una statua 3D (Three.js) nella sezione citazione.

Sezioni: Hero, Statistiche, Filmografia (marquee), Chi Siamo, Citazione con statua 3D, Servizi,
Portfolio/Filmografia con filtri, Materiali e Tecniche, Magazine, Form "Richiedi un Progetto",
Contatti, Footer.

## Anteprima

Basta aprire `index.html` in un browser, oppure pubblicarlo con GitHub Pages
(Settings → Pages → Deploy from branch → `main` / root).

## Note importanti prima di andare online

- **Fotografie**: le immagini attualmente in uso sono fotografie reali ma "segnaposto", tutte a
  licenza libera (Wikimedia Commons, CC0/CC-BY/dominio pubblico — vedi credito nel footer del sito).
  Vanno sostituite con l'archivio fotografico proprio del laboratorio prima della pubblicazione
  definitiva. **Non contengono locandine o fotogrammi dei film citati**: quel materiale è protetto
  da copyright degli studios (MGM, Universal, Miramax, HBO, Cineriz) e non può essere usato senza
  una licenza.
- **Statua 3D**: scansione del *Discobolo* (calco in gesso, collezione SMK — Statens Museum for
  Kunst, Danimarca), rilasciata in dominio pubblico (CC0). Modello incorporato direttamente nel
  file come dato binario (base64), circa 4.6 MB.
- **Contatti placeholder**: numero di telefono, indirizzo WhatsApp e link "Download Media Kit" sono
  segnaposto da aggiornare con i dati reali dell'azienda.
- **Font e CSS**: caricati da CDN esterni (Google Fonts, Tailwind CSS via CDN) — richiede una
  connessione internet per il rendering corretto degli stili e dei caratteri.
